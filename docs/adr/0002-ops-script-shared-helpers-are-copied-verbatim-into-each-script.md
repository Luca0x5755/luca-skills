# 0002：運維腳本的共用函式逐字複製進每一支腳本，不抽成共用檔

Status: Superseded by 0003

日期：2026-11-20

## 脈絡

運維腳本需要一組共用函式：顏色、錯誤輸出、確認、步驟標題、終端機檢查、結果總表、多選器。實測一個專案的十支運維腳本，這些函式各自複製了五到七份，彼此已經走樣：同一個多選器對 Enter、大小寫、越界的處理各不相同，測試模式的變數名甚至沿用別支腳本的。

常理的解法是抽成一個共用檔，讓每支腳本 `source` 它。但運維腳本常在 repo 還不存在的機器上執行 — 初次建置時，部署腳本是從隨身碟單獨帶過去跑的。共用檔不在旁邊，腳本就跑不起來。

## 決定

- `/ops-script` 附 bash 與 PowerShell 骨架各一份，共用函式放在骨架裡以 `BEGIN ops-lib vN` 與 `END ops-lib` 標記框住的區段。
- 每支運維腳本逐字複製這個區段，區段內不准手改。要改，改骨架、升版號，再同步回各支腳本。
- 腳本必須單檔可攜：複製到任何機器、單獨執行都要能跑。

## 否決的做法

- **共用檔 `source` 進來**：單檔可攜性沒了；隨身碟、單獨下載、`scp` 一支腳本過去的情境全部壞掉。
- **照舊各自複製、不加標記**：就是現況，走樣已經被觀察到。

## 代價

- 同步要人做。版號讓走樣看得見：同一專案裡兩支腳本的 `vN` 不同，就表示有一支沒同步。
- 區段的修改要逐支套用；骨架因此要保持小而穩定。
